Technologies et langages
========================

* **Python 3.10** : langage principal.
* **Django 5.2.17** : framework web.
* **flake8 7.3.0** : linting.
* **pytest 9.1.1** et **pytest-django 4.14.0** : tests.
* **coverage 7.15.4** : mesure de couverture.
* **python-dotenv 1.2.3** : variables d'environnement locales.
* **sentry-sdk 2.68.1** : suivi des erreurs.
* **Docker** : conteneurisation.
* **GitHub Actions** : CI/CD.
* **Docker Hub** : registre d'images.
* **Render** : hébergement.
* **Gunicorn 26.2.0** : serveur WSGI.
* **WhiteNoise 6.12.0** : fichiers statiques.
* **Sphinx** : génération de la documentation.
* **Read the Docs** : publication et autobuild de la documentation.
